## 外部サービスの情報を取得するとき

- GitHub の情報を**読む**ときは素の `gh` の読み取り系サブコマンド（`gh pr view`、
  `gh issue list`、`gh run view`、`gh search` など）を使う。これらは
  `permissions.allow` に入っているのでプロンプトなしで実行できる
- `gh api` は読み取りでも毎回プロンプトが出る。同じ情報が読み取り系サブコマンドで
  取れるならそちらを優先する
- 変更を伴う操作（PR のマージ、secret の更新、リポジトリ設定の変更など）は
  従来どおりプロンプトが出る
